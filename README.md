# 小伴 · My Little Companion

簡潔可愛的 OLED 吊飾控制網頁。奶油白、淡桃色、薄荷綠；手機優先，桌面也能使用。

正式網址：https://quadcopteronline.org/

網頁 1.3.4 修正字幕反覆儲存／傳送新增副本：更新正在編輯的作品並保留原 ID，完全相同的字幕沿用既有項目；需要另一個版本時明確「另存新作品」。既有作品與同名不同內容的字幕均保留，不會自動合併或刪除。詳見 [字幕儲存行為](docs/subtitle-saving.md)。

線上使用說明：https://quadcopteronline.org/manual/ 。網頁 1.3.3 加入獨立說明書 QR、可列印附卡，以及裝置頁與頁尾入口。內容可持續修改，保留同一網址即可沿用原 QR；更新方式見 [說明書維護](docs/manual-updates.md)。說明書 QR 不含裝置授權碼，供公開閱讀。

網頁 1.3.0 新增「玩法」：多擊換作品、傾斜眼神、拿起招呼、短按鎖定、低電量策略、八種動作綁定、三種迷你遊戲、時鐘／倒數／番茄鐘、自訂省電及倒拿轉正。C5 0.7.0 提供裝置端功能與 SHA-256 智慧同步；舊韌體保留原控制方式。操作詳見 [日常玩法](docs/daily-play.md)。

網頁 1.3.1 加入字幕位置微調：固定字幕可左右／上下移動，水平跑馬燈可上下移動，垂直跑馬燈可左右移動。滑桿範圍依實際文字大小調整，並提供重設位置；字幕草稿、作品與匯出備份保存位置。偏移在手機轉成點陣時完成，沿用已有字幕功能的韌體，無需重新燒錄。

網頁 1.3.2 修正上下位置原點：固定字幕與水平跑馬燈以實際字形置中，0 px 不再受字型行高的留白影響。舊草稿與作品換算偏移保留已調好的位置；按「重設文字位置」可回到新的中心。詳見 [字幕位置調整](docs/subtitle-position.md)。

網頁由 GitHub Pages 部署，Cloudflare 管理 DNS；`www.quadcopteronline.org` 轉到主網址。原 GitHub Pages 配對網址由平台轉址到新網域，吊飾密鑰不需更換。DNS 與移轉方式見[自訂域名說明](docs/custom-domain.md)。

## 這一版完成的功能

- 六種表情與眨眼預覽；手動表情、自由變換模式。
- 照片裁切、放大、亮度、對比、二值化、Floyd–Steinberg 抖色、反色。
- 32×16、64×32、128×64 像素畫板；畫筆、橡皮擦、填色、復原／重做。
- 逐格複製、新增、刪除、排序、洋蔥皮與 5／8／10 FPS 預覽。
- GIF 合成與 disposal 處理；瀏覽器可解碼影片的抽格；最多 10 秒、100 格。影片／GIF支援0.10～3.00倍縮放、左右／上下位置、完整畫面與重設，調整時更新黑白預覽。
- 作品集、OLA 檔案匯入與匯出。
- 裝置頁顯示作品剩餘／已用容量，以及 C5 0.6.1 以上的即時內部 RAM、使用比例與最大連續可用區塊。
- C5 0.6.0 以上提供裝置頁自動省電開關與實際睡眠紀錄，包含降頻、調暗、淺眠及深眠；接線、條件和電流量測見 [省電指南](docs/c5-power-saving.md)。舊韌體保留既有控制，不開放新省電設定。
- 混合表情／圖片／動畫的播放清單；拖曳及箭頭排序、播放秒數、停用、循環／隨機／一次、手機預覽。
- IndexedDB 草稿、JSON 備份匯入／匯出。備份不包含裝置授權碼。匯入保留原有作品與畫板草稿，以備份取代播放清單。
- 真實 Web Bluetooth GATT 客戶端：HMAC 授權、控制、上傳流量控制、ACK、CRC32、查詢續傳位置、取消、裝置作品列表。
- 網頁殼的 Service Worker 快取；是否能離線開啟仍取決於 Bluefy／iOS 實際支援與是否完成初次快取。

## 手機使用

1. 掃描這台吊飾的專屬 QR Code；網址已包含配對資訊，不用傳檔案或輸入授權碼。
2. iPhone 要使用 BLE，請用 [Bluefy](https://apps.apple.com/tw/app/bluefy-web-ble-browser/id1492822055)。若掃碼先開了 Safari，在網頁按「複製配對網址」，再將完整網址貼進 Bluefy 的網址列。Android 可用支援 Web Bluetooth 的 Chrome。
3. 開啟吊飾，在 5 分鐘內按「尋找小夥伴」，選擇你的小伴 S3／C5。掃描 QR 後授權碼自動填入，成功授權後預設記住在目前瀏覽器。連線後若 10 分鐘沒有上傳作品或同步清單，藍牙會關閉；支援觸摸的 C5 可長按 2 秒重新開放。
4. 把作品加入播放清單，按「同步給小伴」。下次用同一個瀏覽器開控制網址並按「尋找小夥伴」，即可使用這台吊飾已記住的授權碼。Safari 和 Bluefy 的儲存互相獨立；iPhone 請在 Bluefy 完成第一次配對。清除瀏覽器資料或恢復出廠後，需重新掃描有效的配對卡。

QR Code 含有裝置的控制憑證，請和吊飾一起交給使用者；私人 QR 與密鑰不放進公開儲存庫。網頁讀取後會清除網址列上的憑證片段，瀏覽器切換用的完整連結僅留在記憶體；成功授權且選擇記住後，授權碼依裝置 ID 存在目前瀏覽器的 IndexedDB，不包含於作品 JSON 備份。「複製配對網址」會依使用者點選寫入剪貼簿。若自動複製被瀏覽器拒絕，可長按畫面上的完整網址複製。

v0.3.3-s3 支援一般／管理員兩種配對卡。一般卡可交給朋友，恢復出廠後會失效；管理員卡由管理者保管，恢復出廠後仍能授權控制這台吊飾。網頁會依裝置回覆顯示「管理員已授權」。管理員碼只留在本機，取得方式見[韌體說明](firmware/README.md#管理員碼與一般配對卡)。v0.3.4-s3 增加「裝置 → 交接與恢復出廠」：管理員可在網頁完整重設，重開機後重新連線、核對完成紀錄並取得新的朋友配對 QR；也可直接讀取目前的一般卡，儲存圖片或複製網址。

作品只保存在目前裝置、目前瀏覽器的 IndexedDB。Safari 和 Bluefy、不同手機之間不會自動共享草稿；可用 JSON 備份移轉。網頁不會把相片、影片、草稿或授權碼上傳到 GitHub。

## ESP32-S3 韌體

現在另有與網頁`mlc/1`協定一致的[ESP32-S3韌體](firmware/README.md)。沿用已接好的16MB Flash S3、SH1106 128×64、SDA GPIO8、SCL GPIO9，支援表情、亮度、OLA圖片／動畫、播放清單、LittleFS、HMAC授權、5分鐘搜尋窗口與10分鐘上傳閒置關閉。

程式與編譯／上傳／取配對碼工具在`firmware/`；本機備份及私人授權碼不放入儲存庫。驗證範圍見[實機紀錄](docs/firmware-verification.md)。這份 S3 韌體仍未實作安全 OTA 與電池量測。

## 和 C5 韌體的界線

網頁 1.1.0 新增字幕編輯器；搭配本機 C5 0.5.0 韌體，可播放固定字幕、左右跑馬燈、上下捲動、中文直排及表情＋字幕。支援 8～32 px 字體、黑體／明體／等寬、粗體、對齊與 1～120 像素／秒速度。文字以手機字型排版後轉成單色圖，繁體中文和符號以預覽為準；字幕可存成作品、加入播放清單、匯出／匯入與離線播放。可選擇字幕播放時保持亮屏，預設仍保留靜止 60 秒關屏。傳輸與格式見 [字幕協定](docs/subtitle-protocol.md)。

本專案交付網頁，不包含 C5 韌體。BLE 只有在韌體實作 [docs/ble-protocol.md](docs/ble-protocol.md) 的服務、UUID、封包與指令時才會成功；原作者的表情程式本身沒有這些 BLE 功能。

已另外交付相容的 XIAO ESP32-C5 本機韌體。C5 0.4.2 搭配網頁 1.0.14 可在裝置頁顯示電池電壓與標示「約」的估計百分比，前景連線時每 30 秒更新。百分比採通用單顆 4.2 V 滿電鋰聚合物參考曲線，充電時可能偏高，尚未用實際電池放電校準；舊韌體沒有讀值時仍顯示「—」。

C5 0.4.3 搭配網頁 1.0.15 另顯示 USB 資料主機連線狀態，串口程式未開啟也可偵測。USB 資料連線與充電獨立：目前充電狀態訊號尚未接到主控，所以網頁明確顯示「目前無法讀取」，不以電壓或 USB 推算充電；USB 欄位缺資料的舊韌體會顯示「需要更新韌體」。

網頁沒有模擬裝置連線成功、電量或容量。未連線／未授權時，裝置指令會顯示明確提示。廣播窗口、授權與Flash提交由韌體負責；S3使用15秒單次HMAC挑戰，輸入授權碼後才開始取得挑戰。

OTA 刻意不開放傳輸；需先完成韌體端簽章驗證、版本／板型檢查、低電量保護及 Bootloader 回復設定。HMAC 登入不是無線內容加密；傳輸保密與加密鏈路需要另外整合。

## 本機開發

需要 Node.js 20 以上。已提交 GIF decoder 與 QR generator，部署網站不需要 npm 或外部 CDN。QR 使用 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)，配對資料不傳給 QR 服務。

```powershell
npm ci
npm test
npm run check
npm start
```

開啟 http://127.0.0.1:4173/ 。初次下載後也可直接執行 `Start-Web.cmd`，不需安裝套件。瀏覽器 ES modules 必須透過 HTTP／HTTPS 使用，不能直接雙擊 HTML 檔。

修改 GIF 相依套件後執行 `npm run vendor`。`npm test` 驗證 OLA／CRC／像素格式、分包重組、授權挑戰和 mock BLE 上傳，不能代替 C5／Bluefy 實機測試。

## 發布

`.github/workflows/pages.yml` 在推送 `main` 時執行測試、檔案檢查，部署 `web-app/` 到 GitHub Pages。GitHub 儲存庫與網站為公開；公開檔案只有網站程式、文件與測試，不包含朋友的草稿。

## 相容性

- MP4 解碼取決於瀏覽器與 iOS，優先使用 H.264；HEVC／HDR 沒有實機保證。
- GIF 在網頁端以 vendored `gifuct-js` 解碼，無須依賴瀏覽器的 ImageDecoder。
- GIF 上限 40MB、邏輯畫面 4M pixels、2000 原始影格；照片上限 30MB。
- Web Bluetooth 不提供通用的 MTU 查詢 API。本客戶端由裝置 INFO 取得應用封包上限，預設 20 bytes，最大 244 bytes，所有標頭也包含在上限内。
