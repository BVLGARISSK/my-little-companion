# C5 自動省電與電流量測

本頁記錄 C5 0.6.0／網頁 1.2.0 建立的省電機制與量測方法。現行 0.7.11／網頁 1.4.4 沿用並提供自訂時間／方案；以下 15 秒、60 秒、10 分鐘是預設值，自訂後以裝置設定為準。0.7.11 的實測範圍見[目前驗證紀錄](current-verification.md)。

## 使用行為

- 靜止 15 秒：暫時將 OLED 對比限制到 64；若使用者原亮度低於 64，沿用原值。移動／觸摸／控制後恢復原亮度，不覆寫儲存的亮度。
- 靜止 60 秒：OLED Display OFF，暫停作品與清單計時。MPU6050 切到 20 Hz 低功耗加速度 CYCLE 模式，陀螺儀待機、溫度感測關閉；INT 高有效並鎖存至讀取 INT_STATUS。
- BLE 開機 5 分鐘搜尋窗口、曾連線後 10 分鐘沒有上傳／清單同步的窗口保持原規則。窗口結束後停止廣播、斷線，等待傳輸回呼結束再完整停用堆疊／控制器；長按觸摸 2 秒重建 BLE 服務。
- OLED 已關、BLE 已停、沒有上傳／重設、沒有 USB 資料主機且感測器正常時進入淺眠。觸摸 GPIO0 或 MPU INT GPIO1 可喚醒。已確認 INT 時每 1 秒安全醒來檢查 USB；未確認時每 250 ms 醒來讀取加速度，仍可移動喚醒。
- 持續靜止 10 分鐘且已在低功耗模式確認「GPIO1 為高且 MPU 的 motion flag 為真」後，才允許深眠。未確認 INT、感測器故障或讀取失敗時不進入長時間深眠。
- 深眠保留有版本標記和 CRC 的 RTC 播放檢查點：作品 id、表情、清單位置、循環設定和播放時間。移動／觸摸喚醒後恢復；資料無效則回到原本儲存的播放模式並開放 BLE。每 30 分鐘另有安全定時喚醒檢查，正常情況保持 OLED 關閉並再休息。
- 深眠喚醒不會每次重新開 BLE。要用手機時長按 2 秒；真正斷電／重新開機仍開放原本 5 分鐘窗口。
- CPU 依工作需求在 80／160 MHz 切換：離線播放／待機 80 MHz，手機已連線、USB 資料主機、上傳或待處理控制時 160 MHz。這是應用程式管理頻率，沒有更改 Arduino 預編譯 SDK 的 CONFIG_PM_ENABLE，並未宣告啟用維持 BLE 的 Auto Light-sleep。
- BLE 連線閒置 5 秒後請求較長的連線間隔（40～80 ms、latency 4）；有傳輸則請求 15～30 ms、latency 0。手機是否接受由協商結果決定。傳送功率沿用原設定，避免在沒有外接天線時削弱既有連線。
- 表情正常更新間隔 50 ms，搖晃時 33 ms；動畫依檔案 FPS 排程；純固定字幕／靜態圖減少處理，捲動字幕依像素速度排程並限制最密 33 ms。播放清單換件的時間檢查獨立於畫面更新，避免靜態作品延遲換件。
- 板上 L 使用者 LED（GPIO27）關閉；電池分壓開關（GPIO26）平常低電位並在深眠保持，仍每 30 秒短暫量測電壓。

上傳中、恢復出廠中、BLE 窗口內及 USB 資料主機存在時不進整機睡眠。字幕勾選常亮時不自動調暗、不關屏、不進整機睡眠。網頁的「自動省電」可停用降頻、調暗及整機睡眠，原本靜止 60 秒關 OLED 和 BLE 逾時規則仍保留。

## 網頁與協定

裝置頁「省電設定」提供開關、裝置實際回報的 CPU MHz、淺眠次數、深眠喚醒次數及移動中斷確認狀態。它們是診斷次數，不是電流量測或省電百分比。未連線不顯示舊資料；舊韌體不允許套用。

INFO 新增 `power_save` capability 及 `power_save_enabled` boolean。`GET_POWER` 需要授權，讀取快照而不重設靜止／BLE 上傳閒置計時；`SET_POWER {enabled: boolean}` 需要授權，先儲存成功再套用。設定失敗時不回報已儲存。完整恢復出廠會將新開關回到預設啟用。

查詢時 CPU 正在執行，所以 `whole_chip_sleep` 回報 awake；以 last_sleep、light_sleep_count、deep_wake_count 追蹤已發生的睡眠，不能把正在執行查詢的狀態寫成目前在深眠。USB STATUS 增加同樣診斷。原配對碼、作品格式與既有操作保留。

## 電池端電流量測

USB 必須拔掉，以單顆鋰電池供電。電流錶串在電池正極路徑：

```text
電池 BAT+ ── 電流錶紅端（電流輸入）
              電流錶黑端（COM） ── 主板 BAT+
電池 BAT− ────────────────────── 主板 BAT−
```

電流檔要串聯，不能直接跨接電池正負極。使用正確的電流插孔與足以承受開機峰值的量程；依儀器規格選較細量程。量測過程保持接點牢固，換插孔或量程時若切斷供電，需重新等候睡眠。USB 電流表量到的是外接供電／充電路徑，不能直接當成電池放電電流。

先確認感測器低功耗移動喚醒：電池冷開機後不要連手機，放置 65 秒，OLED 熄滅後拿起。接著長按觸摸 2 秒、連手機，確認「移動中斷已確認」。最後斷電重新開始正式量測，避免前次手機連線的 10 分鐘窗口干擾。

所有比較保持同一電池電壓、亮度、畫面、CPU／BLE 條件。亮屏與調暗會受白色像素比例影響，使用同一個表情或固定圖。要比較 BLE 關閉的亮屏狀態：冷開機後不要連手機，等 5 分鐘窗口關閉，再移動／觸摸喚醒，立即量前 15 秒；15～60 秒量調暗。靜止 60 秒後量淺眠，10 分鐘後量深眠。量測當下不要連手機；量完再長按連線查看睡眠紀錄。

| --- | --- | --- | --- | --- | --- | --- |
| 亮屏播放 | 關閉 | 原亮度 |  |  |  | 原畫面、前 15 秒 |
| 調暗播放 | 關閉 | 對比限制 64 |  |  |  | 同一畫面 |
| 淺眠 | 關閉 | 關閉 |  |  |  | 記錄定時醒來的短暫峰值 |

一般萬用電錶可能漏掉短暫峰值；可記錄穩態與峰值範圍，若有記錄型電流分析儀則積分求平均。小量程的負擔電壓可能影響開機／喚醒，若儀器串接後才重啟或喚醒失敗，需先排除量測本身的壓降。

同條件關屏省電比例 = (亮屏平均電流 − 睡眠平均電流) ÷ 亮屏平均電流。整天平均電流 = 各狀態電流 × 各狀態時間比例之和。續航估算需使用電池端平均電流與有效容量；沒有實測前不承諾省電幾成或幾小時。

## 模組 LED 與硬體界線

程式已關閉可控制的主板 L LED。MPU6050／TTP223 模組若有直接接電源的常亮 LED，通常無法由 C5 程式關閉。確認板上實際 LED 與串聯限流電阻後，可移除那顆 LED 或該 LED 專用限流電阻，保留感測器供電、I²C 拉高電阻及 INT／OUT 接線。觸摸感應時才亮的 LED 影響不同，應先量測再決定。

不要切斷 MPU6050 或觸摸模組的整體電源來追求待機數字，否則失去移動／觸摸喚醒。模組穩壓器本身的待機耗電需另量，必要時才評估低功耗模組替換。此文件不表示已實際拆除 LED／電阻，也不表示已量到整機電流。
