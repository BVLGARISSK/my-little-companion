# XIAO ESP32-C5 接線

適用本儲存庫 C5 0.7.11-c5：XIAO ESP32-C5、SH1106 128 × 64 四線 I²C OLED、MPU6050、TTP223 觸摸模組。腳位以 ESP32 Arduino core 3.3.12 的 `variants/XIAO_ESP32C5/pins_arduino.h` 及程式 `Config.h` 核對。

|模組訊號|XIAO 板上標示|實際 GPIO|用途|
|---|---|---|---|
|OLED SDA + MPU6050 SDA|D4|23|共用 I²C SDA|
|OLED SCL + MPU6050 SCL|D5|24|共用 I²C SCL|
|MPU6050 INT|D0|1|移動喚醒，深眠前需驗證中斷|
|TTP223 OUT|D1|0|觸摸、多擊、長按與喚醒|
|OLED／MPU6050／TTP223 VCC|3V3|—|3.3 V 供電|
|三個模組 GND|GND|—|共地|
|單節電池正／負|BAT+／BAT−|—|接主板電池焊盤，依板上極性|

**D0 是 GPIO1，D1 是 GPIO0。** 程式內使用實際 GPIO 編號，不能把板上 D 編號當作 GPIO。

OLED 與 MPU6050 並聯同一組 I²C。OLED 預期位址 0x3C／0x3D，MPU6050 0x68／0x69。MPU6050 AD0 維持模組預設低電位即可；XDA、XCL 不接。觸摸 OUT 使用高有效的即時輸出，不啟用模組自鎖切換模式。各模組以 3.3 V 供電，訊號也維持 3.3 V 邏輯。

程式預設 I²C 400 kHz，偵錯可用 USB `display-safe` 切到 100 kHz；`display-fast` 回到 400 kHz。線長、接點與模組拉高電阻會影響可靠度。不要為追求速度直接改到未驗證的時脈。

MPU6050 裝入外殼後，在手機「玩法」以正常直立姿勢做正向校正；依實際安裝調整軸向與反向。只靠照片不能確認所有感測軸。感測器不在或 INT 未驗證時，深眠條件會受限；裝置頁可查看中斷狀態。

## 電池與 USB

使用與主板充電電路相容的單節鋰電池，確認 BAT 極性與電池保護。電源開關若串在電池路徑，USB 仍可能直接供電；完整冷開機測試需同時拔 USB 並斷開電池電源。

板內電池量測由 GPIO6 與分壓使能 GPIO26 完成，不需再把 BAT 接到任意 ADC。顯示電壓與「約」的百分比；充電時及不同電池的誤差需實測校正。

目前沒有接入充電 IC 狀態訊號，因此「充電：目前無法讀取」是現有硬體能力。USB 資料主機連線只表示資料連接，不足以區分充電器／正在充電／已充滿。此版未包含充電狀態額外改線。

實際整機電流與續航尚未量測，方法見[省電與量測指南](c5-power-saving.md)。
