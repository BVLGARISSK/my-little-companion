# 操作邏輯修正：網頁 1.4.0 / C5 0.7.7

2026-10-15。以已確認的 0.7.6 為基準；暫停中的字幕流暢度實驗未改動。

## 已修正

- 玩法未套用草稿會保留修改狀態，重新整理、授權和狀態輪詢不會覆蓋；手動讀取與跨裝置套用先確認。儲存期間新改的內容仍保留為未套用草稿。
- 預設單擊不再中斷短暫插播的表情，也不會遺失原播放恢復位置；明確自訂的單擊動作仍照設定執行。
- 隨機播放從啟用項目均勻抽選，停用項目的分布不再影響機率。連續抽中同項仍可能發生。
- 手機預覽尊重動畫不重複設定，播放一次後停在最後一格。
- 關閉倒拿自動轉正後恢復固定正向，不會停在倒向。
- 未連線時停用需要裝置的按鈕，更新觸摸與省電提示，修正 320 px 清單工具列溢出。

## 新的清單管理流程

1. 新手機授權後，到「播放 → 讀取吊飾清單」。取得清單與作品名稱；檔案仍留在吊飾，沒有本機檔案時不提供編輯預覽。
2. 可調整順序、秒數、啟用與播放模式。讀回前草稿可還原一次。
3. 按同步會比較吊飾現況並詢問新增／移除等差異，確認後重新開始播放。韌體會檢查清單版本，拒絕過期覆蓋。
4. 清空手機草稿後同步並確認，吊飾才清空清單並回到表情。作品、授權碼保留。
5. 要刪除被引用作品，先從清單移除並同步；若仍被動作規則引用，再解除綁定並套用。
6. 頁首顯示目前播放，連線且頁面可見時約每 5 秒更新。手機草稿與手機預覽不代表吊飾實況。

舊韌體仍可用既有功能；讀回清單、目前播放及清空吊飾清單需 C5 0.7.7。自動記住授權碼維持原功能。
