# 字幕播放用途

網頁 1.4.3；C5 0.7.10。0.7.10 以 0.7.7 為基礎，不含小恐龍，也沒有套用未完成的字幕時序／ADC 實驗。

- 固定播放：傳送作品後發出 PIN_SUBTITLE。拿起、晃動與短按均不切換；長按開藍牙與鎖定、原本省電照常。NVS 以單一 pin_caption 字串保存字幕 ID；RTC checkpoint 保存固定狀態。更新 RTC 布局識別碼，避免解讀舊布局。
- 加入播放清單：僅加入手機草稿，避免相同字幕重複加入。同步更新裝置清單；若正在固定播放，持續原字幕，直到使用者主動切回。
- 停止固定播放：UNPIN_SUBTITLE 先解除保存狀態，再回到清單；沒有可播清單時回自動表情。一般 PLAY_MEDIA、PLAY_PLAYLIST、SET_EMOTION 亦會解除保存的固定字幕。
- 正在固定播放的作品須先停止，才能刪除。恢復出廠會清除 pin_caption，管理員授權的原規則不變。
- INFO 用 subtitle_pin 能力宣告支援；舊版不會假裝已固定。新版的可選小恐龍須明確宣告 dino；僅 0.7.8/0.7.9 保留版本推定，避免無小恐龍的 0.7.10 出現可執行按鈕。
