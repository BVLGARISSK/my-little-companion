# 字幕位置調整（網頁 1.3.2）

在「字幕」頁，先選顯示方式，再使用「左右偏移」與「上下偏移」。負值向左／向上，正值向右／向下。固定字幕與水平跑馬燈的「上下 0 px」以實際點亮字形的上下邊界置中；左右 0 px 沿用所選對齊。「重設文字位置」將偏移歸零，保留字體、對齊與播放設定。

| 顯示方式 | 可調方向 |
|---|---|
| 固定字幕 | 左右與上下 |
| 水平跑馬燈 | 上下 |
| 垂直捲動字幕 | 左右 |
| 表情＋字幕 | 依顯示方式，在下方字幕區內調整 |

位置範圍依實際點亮像素計算，避免移動後裁切。字體較大或字幕占滿可用區域時，可移動範圍會變小，無空間的滑桿會停用。預覽即時更新，草稿與字幕作品保存偏移；已傳入吊飾的字幕，調整後要再按「傳送並播放」。從作品集開啟字幕，按「複製到字幕編輯」可調整舊作品並另存。

位置直接寫進手機產生的文字點陣，既有字幕韌體不需更新，也不依賴 0.7.0 的玩法功能。原本作品缺少位置欄位時沿用 0 偏移，不移動舊點陣。表情與字幕的分區沿用原設定，不會把文字移入表情區。

1.3.2 修正原本用字體行高置中造成的上下偏差。各手機、黑體／明體／等寬及字體大小的留白不同，因此不使用固定 -5 px 補償。編輯資料以 `position_version=2` 記錄新原點；舊草稿／作品重新編輯時，將舊偏移換算成新原點，保留原本像素位置，不重複位移。若想改用真正置中，按「重設文字位置」後重新傳送。此欄位不傳入裝置 runtime。
