# 字幕回到播放清單（網頁 1.3.5）

字幕頁新增「回到播放清單」，與裝置頁原有的同名按鈕共用操作。連線授權後送出 PLAY_PLAYLIST，讓吊飾依清單的循環／隨機／單次模式重新開始最後同步的清單。

此操作不儲存字幕、不產生新作品、不上傳檔案，也不將手機清單草稿覆寫到吊飾。手機修改過清單時，仍須到「播放」按「同步給小伴」。沒有啟用且可播放的項目時，吊飾保留原畫面，網頁提示先加入啟用項目並同步。

網頁指令沿用既有協定，原 C5 0.7.3 就能使用。C5 0.7.6 新增的實體操作為：單獨播放字幕時，預設單擊觸摸區返回清單；清單中的字幕、圖片及動畫維持原單擊規則。自訂單擊、短按鎖定、第一次觸摸喚醒、遊戲／計時等操作優先保留。此韌體在獨立本機分支編譯及提供回滾，燒錄與實機驗證狀態以本機報告為準。

0.7.6 也整合「下一個／上一個只選清單啟用項目」的修正。清單外作品仍可由手機明確選播或由明確的作品互動綁定播放。未列入清單的字幕不再參加下一個／上一個輪播。

## 驗證

- 110 項既有 Node 測試及 36 個網站檔案、JS 語法、UI id、離線資源檢查通過。
- Chromium 320、393、768、1280 寬度：新舊返回按鈕只送 PLAY_PLAYLIST，手機字幕與清單草稿前後一致；未連線、未授權、傳輸中與重複操作均被攔截；空清單顯示中文提示，失敗後可重試。
- 玩法的預設單擊標籤依連線韌體調整；0.7.3-c5、0.7.6-c5、0.7.10-c5、0.8.0-c5、1.0.0-c5、0.7.6-s3 的版本分界通過瀏覽器檢查。
- 四個尺寸無水平溢出或頁面錯誤，393px 截圖已目視確認。使用模擬傳輸，未將結果當作實機 BLE／觸摸測試。

控制頁及離線快取升為 1.3.5；說明書升為 1.2，網址與全部 QR 圖檔維持原本內容。原授權碼記憶機制與 IndexedDB 格式不變。原字幕卡頓實驗維持暫停。
