# 字幕重複儲存修正（網頁 1.3.4）

原本「存成字幕作品」與「傳送並播放」每次都產生新作品 ID，名稱預設「我的字幕」，所以重複傳送及修改會累積多張同名卡片。這不是單一項目被畫兩次。

- 新字幕第一次保存會加入作品集，之後儲存／傳送會更新這一件，保留 ID 與原建立時間。
- 在作品預覽按「編輯字幕」會選定原作品。重新整理後，編輯中的作品 ID 仍保存在目前瀏覽器草稿。
- 新增前，僅在名稱、完整字幕設定、FPS 與每個圖塊的像素完全相同時沿用既有作品。相同名稱、不同文字／表情／速度／位置／像素仍是不同作品。
- 「另存新作品」明確建立新 ID；同名時加上（2）、（3）等序號，原版保留。
- 單件字幕匯入也沿用完全相同的作品。完整 JSON 備份匯入仍維持原本的保留與 ID 重新映射規則。
- 已存在的重複項目不批次刪除；清單與動作規則保留引用。編輯同一 ID 的手機作品後，要重新傳送／同步，吊飾才會取得新版內容。

本次只修改網頁。沒有讀取、清除或燒錄實體吊飾；授權碼儲存與一般／管理員配對流程不變。說明書更新到 1.1，沿用同一網址和原說明書 QR。

驗證：110 項 Node 測試及 36 個網站檔案檢查通過；Chromium 在 320／393／768／1280 px 寬度測試重複儲存、兩次模擬傳送、修改保留 ID、明確另存、重載恢復編輯、純文字／表情版分離、相同字幕匯入沿用及作品預覽進入編輯，均通過且無橫向溢出。傳輸使用測試替身，不代表本次另做了實機 BLE 傳輸。沒有存取手機既有草稿。
